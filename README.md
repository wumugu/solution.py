# Белковые цепи — НТО

Решение задачи на сопоставление измеренных белковых цепей с последовательностями из корпуса.

## Идея

Для каждой измеренной цепи:

1. Перебираем все последовательности из корпуса.
2. Сразу пропускаем последовательности другой длины.
3. Для последовательностей одинаковой длины считаем количество несовпадающих позиций.
4. Запоминаем вариант с минимальным числом ошибок.
5. Если ошибок не больше 10, выводим:
   ```text
   номер_измерения номер_последовательности
   ```

Нумерация начинается с **нуля**.

Подсчёт ошибок выполняется так:

```python
sum(a != b for a, b in zip(chain, known_chain))
```

`a != b` даёт `True` или `False`, которые Python суммирует как `1` или `0`.

## Файлы

- `solution.py` — решение;
- `twc12_protein_chains.txt` — измеренные белковые цепи;
- `twc12_protein_corpus.txt` — корпус эталонных последовательностей.

## Запуск

Положите три файла в одну папку и выполните:

```bash
python solution.py
```

## Сложность

Пусть:

- `N` — количество измеренных цепей;
- `M` — количество цепей в корпусе;
- `L` — их типичная длина.

В худшем случае алгоритм работает за `O(N * M * L)`.
